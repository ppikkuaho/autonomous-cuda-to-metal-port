# Compatibility Matrix

This matrix tracks actionable compatibility decisions, the result of a static
scan of the upstream tree for CUDA and backend assumptions.

| CUDA/Linux component or assumption | Pixal3D location | Purpose | Mac strategy | Verification | Status | Notes |
|---|---|---|---|---|---|---|
| `flash_attn` / `xformers` | attention modules / env defaults | transformer attention | PyTorch SDPA for the selected Mac inference path | `test_030_sdpa.py`, end-to-end geometry runs | pass | Runs used `ATTN_BACKEND=sdpa`, `SPARSE_ATTN_BACKEND=sdpa`, and strict MPS fallback disabled |
| `flex_gemm` sparse conv | `pixal3d/modules/sparse/conv/*` | sparse 3D submanifold convolution | `SPARSE_CONV_BACKEND=none` via pure PyTorch `conv_none.py`; revisit `mtlgemm` later for acceleration | `test_050_sparse_conv.py`, end-to-end geometry runs | pass | Correctness fallback covers dispatch, CPU/MPS reference matching, sparse reductions, duplicate-coordinate rejection, stale-cache safety, empty tensors, streaming/chunked lookup, and a `SparseConvNeXtBlock3d` smoke. Slow and submanifold-only; dense 12-step high-res latent replay still hits scale limits. |
| `flex_gemm` grid sampling | `pixal3d/representations/mesh/base.py` | 3D attribute sampling for mesh/texturing | guarded import; the fallback texture exporter avoids it via voxel-coordinate color lookup | mesh-extraction and texture-export checks | partial | `query_attrs` still raises if called without a backend; the selected exporter does not need it |
| `o_voxel.convert.flexible_dual_grid_to_mesh` | `pixal3d/models/sc_vaes/fdg_vae.py` | dual-grid mesh extraction from decoded shape latents | local pure Python/PyTorch fallback in `pixal3d/utils/mesh_extract.py` | `test_060_mesh_extract.py`, CUDA mesh-replay check, `validate_glb.py` | pass | Synthetic quad/empty cases pass on CPU/MPS; `fdg_vae` imports without `o_voxel._C`; the CUDA 12-step FDG tensor mesh replay matched CUDA native vertex/face counts exactly. |
| `o_voxel.postprocess.to_glb` | `inference.py`, texturing paths | final textured GLB postprocess/remesh/bake | fallback `trimesh` UV texture export from decoded voxel base-color attributes | `tests/test_090_geometry_smoke.py`, the fallback texture-export run, `validate_glb.py` | pass | Produces a loadable textured GLB with one texture visual/material; not CUDA `o_voxel` quality-equivalent |
| `cumesh` | mesh cleanup and texturing | hole filling/simplification | skip initially or replace with later simplification | GLB validation, render checks | partial | import guarded in mesh base; cleanup is skipped when unavailable |
| `nvdiffrast` / `nvdiffrec_render` | renderers/texturing | rasterization and texture baking | not used by the selected fallback exporter | texture-export run | deferred | Future quality work can revisit Metal rasterization; the current artifact validates execution/export, not CUDA-quality baking |

| `torch.cuda.*` cache/runtime | inference/app/training/data code | cache, synchronization, diagnostics | guarded no-op or device-specific sync/cache helper | `test_020_device_hygiene.py` | partial | Inference-critical pipeline calls patched; training/toolkit deferred |
